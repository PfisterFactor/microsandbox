Microsandbox dnf repo

Fork: PfisterFactor/microsandbox — updated on every push to main.

Install on Fedora

sudo dnf config-manager addrepo --from-repofile=https://pfisterfactor.github.io/microsandbox/microsandbox.repo
sudo dnf install microsandbox

After install, verify:

msb --version
ldd $(which msb) | grep libkrunfw

Update

sudo dnf update microsandbox
